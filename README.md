# TodoList

Full-stack приложение для управления задачами с CRUD-функциональностью.

## Стек

TypeScript, React, Zustand, Axios, Vite

## Установка

```bash
git clone https://github.com/Granit-700/todolist-client.git
cd todolist-client
npm i
```

## Запуск

Создать `.env` файл и вставить:
```
VITE_API_URL=https://todolist-server-rzg6.onrender.com
```
Команда для запуска:
```bash
npm run dev
```

> [!WARNING]
> Бэкенд на Render free при первом запуске может потребоваться подождать около 1 минуты
